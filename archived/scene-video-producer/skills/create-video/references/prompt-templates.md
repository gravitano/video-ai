# Prompt templates

Use these as starting points, replacing bracketed variables with the shot sheet and style bible. Adapt to the actual image/video tool's input format. Prefer one focused prompt per asset. Reference the approved character frame for each new shot; use prior keyframes as additional references only when needed.

## Creative producer prompt

```text
Act as the creative producer for a [DURATION] vertical short video about [TOPIC] for [AUDIENCE] on [PLATFORM]. Goal: [OBJECTIVE]. One message: [KEY_MESSAGE]. CTA: [CTA]. Language: [LANGUAGE]. Visual tone: [TONE].

Use S.C.E.N.E.: Strategy, Creative, Establish Visuals, Narrative Motion, Edit & Export. Return a creative brief, full voice-over, timed shot sheet, style bible, one keyframe prompt and one motion prompt per shot, then an editing plan. Ensure shot durations total [DURATION] and the VO can be read in that time. Flag assumptions and decisions still needed.
```

## Reference/character frame

```text
Original [CHARACTER] in [OUTFIT], inside [ENVIRONMENT]. Establish stable facial features, outfit details, workspace layout, props, palette [PALETTE], lighting [LIGHT], and rendering style [STYLE] for all future shots. Vertical 9:16. [FRAMING]. Leave safe space for later text overlay. No readable text, subtitles, logos, or watermarks.
```

## Shot keyframe

```text
Use the approved reference as the identity and environment anchor. Shot [N], [START–END]: [ACTION AND NARRATIVE STATE]. Same character face, outfit, room, palette, and rendering style. Camera/framing: [ANGLE]. Mood/light: [LIGHT CHANGE]. Preserve vertical 9:16 and safe overlay space. No readable text, captions, logos, watermarks, new characters, or unrelated objects.
```

## Image-to-video motion

```text
Animate the supplied Shot [N] keyframe for [DURATION]. Subject: [ONE OR TWO CONTROLLED ACTIONS]. Camera: [ONE CAMERA MOVE]. Environment: [SUBTLE SECONDARY MOTION]. Timing: [BEAT ORDER]. Preserve the exact character appearance, clothing, room layout, composition, and style. Natural motion. No new text, subtitles, logos, scene transitions, or camera cuts.
```

## Example: SDD reveal

```text
Keyframe: In the same nighttime studio, the original developer looks up from the laptop as a clean cyan software specification board appears. Four empty connected modules, simple flow arrows, decision nodes and checkmarks. Calm reveal after the chaos. Same face, black hoodie, navy/cyan/amber lighting and 9:16 frame. No labels or lettering.

Motion: Over five seconds, the developer slowly lifts his gaze. The chaotic red panels fade; four cyan modules illuminate in sequence. Gentle push-in and subtle screen reflections. Keep the same face, outfit, room and framing. No generated text or transition.
```
